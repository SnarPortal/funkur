# Skvett

Tekni- og søguforrit hjá Snar: tekna, lita, set figurar á arkið, gev teimum rørslur og ljóð, og ger søgur, framsýningar, filmar og teknirøðublað.

`index.html` er gjørd úr keldufílunum við `bygg.py` (ikki broyta hana beinleiðis).
Søgurnar hjá børnunum verða goymdar í kaganum (IndexedDB) á hesi adressuni; einki verður sent nakran stað.
